# 배경음악 파일

테마별 배경음악 두 곡을 다음 이름으로 사용합니다.

- `village-1.mp3`, `village-2.mp3`: 광장, 마을, 주택, 치유소, 도서관, 성
- `explore-1.mp3`, `explore-2.mp3`: 길, 숲, 황야, 던전
- `battle-1.mp3`, `battle-2.mp3`: 전투

테마가 처음 시작될 때 두 곡 중 하나를 무작위로 선택합니다. 같은 테마 안에서 장소를 이동할 때는 현재 곡을 유지하고, 곡이 끝나면 직전 곡을 제외한 다른 곡을 재생합니다. 마을·탐험·전투 테마가 바뀌면 해당 테마에서 다시 무작위로 선택합니다.

음원은 너무 크게 마스터링하지 않고, 시작과 끝이 자연스럽게 이어지는 버전을 사용합니다.
효과음은 브라우저에서 직접 생성하므로 별도의 효과음 파일이 필요하지 않습니다.
